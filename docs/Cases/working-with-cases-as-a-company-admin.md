# Working with Cases as a Company Admin

## Before You Begin

Make sure the following are in place before creating or managing support cases as a Company Admin:

* **CxCentral access with admin privileges.** You'll need a CxCentral account with company admin permissions, using credentials provided by your organization.
* **Understand your reach.** As a company admin, you can create cases, edit open cases, view all cases across your organization, manage contact profiles, and bulk-edit case statuses. This is broader than a General User, who can only submit and view their own cases.
* **Gather case details ahead of time.** Have the title, case type, priority, product, module, and a clear description ready, plus any attachments, so you can complete the Create a Case form in one pass. Priority can't be selected until you've chosen a Case Type.
* **Line up your CC recipients.** Decide who should be kept in the loop before you create the case. CC'd recipients receive email notifications for any case activity, so confirm their addresses up front.
* **Set up contact profiles.** If you're managing contacts, have each person's name and email ready (both required); all other details are optional. Profiles let you tie cases back to the right people in your organization.
* **Check your attachments.** Confirm each file is within the size and format limits below before uploading.

***

## Limits and Constraints

Keep the following limits in mind when using Cases:

* **Closed cases can't be edited.** To make changes to a closed case, you must reopen it first.
* **Attachment size.** Each file must be 10 MB or smaller.
* **Supported file types.** Only JPG, PNG, PDF, DOC, XLS, CSV, and ZIP files can be attached.
* **Preview limitations.** PDF, CSV, and DOC files can't be previewed in the attachment box—they must be downloaded to open on your computer.
* **Fixed status options.** Case status is limited to the available set: Open, Pending, Closed, In Progress, Waiting on Customer, and Waiting on Third Party.
* **Company name is locked on profiles.** When editing a contact profile, you can update general information, phone numbers, and address details, but you can't change the company name.
* **Required profile fields.** A name and email address are required to create a profile; everything else is optional.
* **Notifications are automatic.** Editing a case triggers an email notification detailing the changes.

## Step-by-Step Instructions  <a href="#submit-a-case" id="submit-a-case"></a>

### Create a Case

1. Go to [https://portal.pronetx.com](https://portal.pronetx.com/).
2. Sign in with the credentials your organization provides.
3. Click **Support** in the top right corner of the screen. This takes you to the Create a Case page.
4. Enter a **Title**. The **Company** and **Reported By** fields are pre-filled with your own company and profile — both stay editable if you're filing the case on behalf of someone else.
5. Select a **Case Type**, then choose a **Priority**. Priority stays disabled until you've chosen a Case Type, and each Priority option shows a short description of when to use it (for example, Urgent means no access to the platform).
6. Select a **Product** and a **Module** to classify what the case is about. The Module options depend on the Product you pick.
7. Add a **Description**, and attach files or add CC recipients as needed. All CC'd recipients will get email notifications for any case activity. Descriptions have a 3,000-character limit.
8. Click **Save**.


**Note:** If you open **Create a Case** from the support icon while viewing a specific module (for example, ACGR or Access Management), Product and Module are pre-filled to match what you were viewing. You can still change them before saving.

### View All Cases

You can view your case history and all cases submitted across your organization. This provides information on case trends, product issues, and user profiles.

1. Log in to CxCentral.
2. Go to the menu on the left side and expand **Cases**.
3. Click **View all Cases**.

***

### Edit a Case

1. On the cases dashboard, click the **Reference Number** for the case you want to edit. This opens the Case Details page.
2. On the Case Details page, click **Edit Case**.
3. Edit the case details — including **Case Type**, **Priority**, **Product**, and **Module** — and add attachments or comments to the case.
4. Click **Update** to apply your changes.

Once case details are updated, you'll receive an email notification detailing the changes.


**Note:** You can't edit a case if it's Closed. You need to reopen a closed case to make any edits.


***

###  Add Attachments

1. Click the **Reference Number** of a case to open the case details page.
2. Under the case details, upload images and files in the attachments box. You can drag and drop or click the attachments box to select files from your computer.
3. Once attachments are added, you can preview the file in the attachment box. If a preview is not available, click the **Download button** to open the file on your computer.


**Note:** Some file types (PDF, CSV, and DOC) cannot be previewed in the attachment box but can be downloaded and opened on your computer. The maximum file size is 10 MB per file. Supported file types include JPG, PNG, PDF, DOC, XLS, CSV, and ZIP.


***

### Add Comments <a href="#add-comments" id="add-comments"></a>

1. Click the **Reference Number** of a case to open the case details page.
2. Under case detail, scroll down to the Comments box.
3. Enter your comment in the text box and click **Submit Comment**. The Comments section shows all conversation and notes for the case.

***

### Bulk Edit Cases <a href="#bulk-edit-cases" id="bulk-edit-cases"></a>

1. On the cases dashboard, select the cases you want to edit.
2. Choose the status from the status dropdown for the selected cases. You can choose Open, Pending, Closed, In Progress, Waiting on Customer, or Waiting on Third Party.
3. A pop-up confirms the status change for the selected cases. Click **Confirm** to apply your changes.

***

### Search and Filter Cases <a href="#search-and-filter-cases" id="search-and-filter-cases"></a>

The cases dashboard displays comprehensive case information across your organization, including Status, Reference Number, Title, Priority, Case Type, Creation Date, and Last Updated Date. You can use the filters to quickly search for cases or collect data about your organization’s support trends.

1. On the cases dashboard, use the **Search by** dropdown at the top of the page.
2. Use the **Status dropdown** at the top of the page to filter by case status or click the **calendar icon** to search using a date range.

Use these filters to identify patterns, track product issues, and analyze support trends across your organization.

***

### View Case Details <a href="#view-case-details" id="view-case-details"></a>

1. Click the **Reference Number** of any case to open the case details page.
2. Review the comprehensive overview including the summary, description, activity, comments, and attachments.

This allows you to understand user issues in depth and identify areas where users are experiencing difficulties with products.

***

### Create Profiles <a href="#create-profiles" id="create-profiles"></a>

Profiles allow you to easily view and manage contacts and information associated with your organization.

1. Go to the menu on the left side and expand **Cases**.
2. Click **Contacts**.

### View Profiles <a href="#view-profiles" id="view-profiles"></a>

1. Go to the menu on the left side and expand **Cases**.

The Contacts Management page shows the total number of profiles and cases and lists the profiles in your company.

***

### Search for Profiles <a href="#search-for-profiles" id="search-for-profiles"></a>

1. On the Contacts Management page, enter a name in the search bar.
2. Use the Status dropdown to toggle between Active and Inactive profiles.

***

### Edit Profiles <a href="#edit-profiles" id="edit-profiles"></a>

1. On the Contacts Management page, navigate to the profile you want to edit.
2. In the Actions column, click the **pencil icon**.

4. Click **Update Profile** to apply your changes.

## Export Cases

The Export Cases feature in CxCentral allows you to download case data from the Cases module as a CSV (Comma-Separated Values) file. You can apply filters within the Export dialog to control which cases are included in the exported file. This is useful for reporting, auditing, and offline analysis of your case data.

**Key Points:**

* The export generates a CSV file that can be opened in spreadsheet applications such as Microsoft Excel or Google Sheets.
* Filters applied in the Export dialog are independent of the filters on the main Cases table. Changing filters in the Export dialog does not affect the table view.
* You can filter by Status, Priority, Case Type, and Date Range before exporting.

### How to Export Cases

1. Navigate to the View All Cases page.
2. Locate the **Export button** in the upper-right toolbar area, above the cases table.
3. Click the **Export button**.

### Export Filters

The Export Cases dialog provides the following filter options to narrow down which cases are included in the CSV export. Each filter is described below.

#### Search

The Search field at the top of the Export dialog reflects the search term currently applied on the main Cases table. It displays "No search applied" if no search is active.

!!! info ""
    This field is read-only within the Export dialog (indicated by a lock icon). To change the search term, close the Export dialog, update the search on the main Cases page, and then reopen the Export dialog.


#### Status

The Status filter is a multi-select dropdown that allows you to select one or more case statuses to include in the export. The dropdown label displays the primary selection and a count of additional selected statuses.

**Available status options:**

<table data-header-hidden="false" data-header-sticky><thead><tr><th>Status</th><th>Description</th><th>Default Selection</th></tr></thead><tbody><tr><td>Open</td><td>Cases that are currently open and active.</td><td>Selected</td></tr><tr><td>Pending</td><td>Cases awaiting further action or information.</td><td>Selected</td></tr><tr><td>Closed</td><td>Cases that have been resolved and closed.</td><td>Not selected</td></tr><tr><td>In Progress</td><td>Cases currently being worked on.</td><td>Selected</td></tr><tr><td>Received</td><td>Cases that have been received but not yet actioned.</td><td>Not selected</td></tr><tr><td>Waiting on Customer</td><td>Cases where a customer response is needed.</td><td>Selected</td></tr><tr><td>Waiting on Third Party</td><td>Cases waiting on an external party.</td><td>Not selected</td></tr></tbody></table>

To change the status filter, click the Status dropdown, then check or uncheck the statuses you want to include or exclude from the export.

#### Priority

The Priority filter allows you to limit the export to cases of a specific priority level. By default, it is set to "All priorities", which includes all cases regardless of priority.

Available priority options:

* Low
* Medium
* High
* Urgent

#### Case Type

The Case Type filter allows you to limit the export to cases of a specific type. By default, it is set to "All case types", which includes cases of every type.

Available case type options:

* Bug Report
* CxPortal Feature Request
* Technical Support
* Alarm
* Account Issue
* Other

#### Date Range

The Date Range filter allows you to limit the export to cases created within a specific time period. By default, no date range is applied (all dates are included).

To set a date range:

1. Click the **calendar icon** next to the dropdown, labeled "Date Range".
2. A date picker opens, showing a dual-month calendar view (e.g., the current month and the next month).
3. To select a custom date range, click on a start date and then click on an end date on the calendar. Use the left and right arrows to navigate between months. Alternatively, use one of the quick select presets on the right side of the date picker (see table below).
4. Click **Update** to apply the selected date range, or click **Cancel** to discard changes.

**Date Range Quick Select Presets:**

<table data-header-hidden="false" data-header-sticky><thead><tr><th>Preset</th><th>Description</th></tr></thead><tbody><tr><td>Today</td><td>Includes only cases from today.</td></tr><tr><td>Yesterday</td><td>Includes only cases from yesterday.</td></tr><tr><td>Last 7 days</td><td>Includes cases from the past 7 days.</td></tr><tr><td>Last 14 days</td><td>Includes cases from the past 14 days.</td></tr><tr><td>Last 30 days</td><td>Includes cases from the past 30 days.</td></tr><tr><td>This Week</td><td>Includes cases from the current calendar week.</td></tr><tr><td>Last Week</td><td>Includes cases from the previous calendar week.</td></tr><tr><td>This Month</td><td>Includes cases from the current calendar month.</td></tr><tr><td>Last Month</td><td>Includes cases from the previous calendar month.</td></tr></tbody></table>

### Executing the Export

After configuring your desired filters:

1. Review your selected filters in the Export Cases dialog to confirm they match the data you want to export.
2. Click the **Export button** at the bottom-right of the dialog.
3. A CSV file will be generated and downloaded to your browser’s default download location.
4. To cancel the export without downloading, click **Cancel** or the **X icon** in the upper-right corner of the dialog.

## Reviewing the Metrics Dashboard

The Metrics Dashboard provides a centralized, real-time overview of your case management activity within CxPortal. It is designed to give support managers, team leads, and agents immediate visibility into case volume, status distribution, priority breakdown, and resolution performance across all companies or a selected company.

### Accessing the Metrics Dashboard

To access the Metrics Dashboard, navigate through the left sidebar menu:

1. Click **Cases** in the left sidebar to expand the Cases submenu.
2. Click **Metrics Dashboard**.

## Filtering Dashboard Data

The Metrics Dashboard provides two filters located in the upper-right area of the page. These filters control the data displayed across all summary cards, charts, and the Recent Cases table.

### Company Filter

The Company Filter is a dropdown labeled “All Companies” by default. It allows you to narrow all dashboard metrics to a single company or view data across all companies.

1. Click the dropdown to open the list of available companies.
2. Use the **Search Company…** text box at the top of the dropdown to quickly find a company by name.
3. Select a company to filter, or select **All Companies** to reset the filter.
4. The currently selected option is indicated by a checkmark.

### Date Filter

The Date Filter button, labeled “Filter by date,” opens a calendar-based date range selector. It allows you to narrow the dashboard data to a specific time period.

## Queue and Date Analysis

Below the Metrics Breakdowns section, two additional panels provide insights into case distribution by queue and case creation trends over time.

### Cases by Queue

This panel displays a horizontal bar chart showing how cases are distributed across the available support queues. Each queue entry includes:

* A color-coded dot identifying the queue.
* The queue name.
* The case count and percentage of total cases.
* A proportional horizontal bar representing the relative volume.
* A “Total cases in queues” summary count is displayed at the bottom of this panel.

### Cases by Date

This panel displays a vertical bar chart showing the number of cases created per day. Key features:

* Defaults to a Last 7 days view.
* The X-axis displays individual dates (e.g., 20 Jun, 21 Jun, 22 Jun).
* The Y-axis displays the case count.
* A Total count is shown in the top-right corner of the panel.
* This panel has its own Last 7 days filter button, allowing you to adjust the time range independently of the global date filter.
