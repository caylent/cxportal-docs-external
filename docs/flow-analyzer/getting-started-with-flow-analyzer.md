# Getting Started with Flow Analyzer

## How to Access Flow Analyzer

1. Log in to CxPortal.
2. In the left sidebar, go to **Flow Insights** > **Flow Analyzer**.

The first thing you see is the contact list panel on the left.

***

### The Contact List Panel

At the top of the panel, you find:

* A search bar for entering a Contact ID
* A **Live Contacts** checkbox to show only active interactions
* An **Advanced** link to open detailed filtering options

Below this, the panel shows a list of recent contacts. For each contact, you can see:

* The channel type (voice, chat, email, or task), shown with an icon such as a phone for voice calls
* The direction of the interaction
* The duration
* The date and time the interaction occurred

This view helps you quickly scan and select the interaction you want to review.

***

### Your First Task: Find a Contact and Open It in Flow View

Try it: locate an interaction and see its journey.

1. Copy a Contact ID from a log, ticket, or report.
2. Paste the Contact ID into the search bar. You do not need to apply a date filter — Flow Analyzer returns the contact as long as it is still available in the system.
3. Select the contact from the list. It opens in Flow View, showing exactly how the interaction progressed through the contact flows.
4. Review the path taken by the contact and look for failed paths, error nodes, or unexpected branches.

!!! info ""
    **Info:** Every customer interaction in CxPortal is a contact. If you don't have a Contact ID, click **Advanced** to filter by timeline, agent, queue, channel, or contact attributes instead — see [Investigating a Contact.](investigating-a-contact.md)
