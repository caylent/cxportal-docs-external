# Manage Sender Identities

## Before You Begin

* You must have admin or campaign management permissions.
* Only verified domains can be used to create sender email addresses.

The Sender Identities page lets you manage the verified email addresses used as the “from” address in your campaigns. The page displays a table of all sender identities with the following columns:
* **Email** (sortable) — The sender email address
* **Display Name** — The name displayed to recipients
* **Sender Name** — The sender’s name on record
* **Description** — An optional description of the sender identity
* **Status** — The verification status (e.g., Verified)
* **Last Verified** (sortable) — The date the identity was last verified

You can search sender identities using the search bar, which supports searching by email or display name. Use the Show Filters button to access additional filter options.


***

## Limits and Constraints

Keep the following in mind when working with sender identities:

* Managing sender identities (adding, editing, or removing) requires admin or campaign management permissions.
* The email address of a sender identity cannot be changed after it is created. Only the display name, sender name, and description can be edited. To use a different email address, add a new sender identity.
* The search bar matches only the email and display name fields. The sender's name and description columns are not searchable.

***

## Step-by-Step Instructions

### Adding a New Sender Identity

1. Navigate to **Campaigns** and click **Sender Identities**.
2. Click **Add new sender** in the top-right area of the table.
3. Fill in the required fields for the new sender identity, including the email address, display name, sender name, and description.
4. Submit the form to create the sender identity.

***

### Editing a Sender Identity
1. Navigate to **Campaigns** and click **Sender Identities**.
2. Click the **actions menu** on the right side of the sender you want to edit.
3. Click **Edit Sender**.
4. Edit the display name, sender name, and description.
5. Click **Save Changes**.


***

### Remove a Sender Identity

1. Navigate to **Campaigns** and click **Sender Identities**.
2. Click the **actions menu** on the right side of the sender you want to remove.
3. Click **Remove Sender**.
4. Review the confirmation message and click **Remove Sender**.


***
