# User Management

## Overview

User Management lets you manage your users and their assigned roles within your organization. You can see each user's name, user ID, login methods, and role, add users, and edit or disable existing ones.

***

## Who Uses This

**Administrators** — add users, keep user information and roles current, deactivate users, and control who has access to the organization's tools and resources.

***

### Key Concepts

| Term                  | Definition                                                                                                                                                                                                                           |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **User ID**           | A unique identifier associated with each user within the system. Optional.                                                                                                                                                           |
| **Role**              | A designation assigned to a user that determines their permissions and level of access within the system.                                                                                                                            |
| **Role-Based Access** | A permissions model where a user's ability to perform actions is determined by the role assigned to them by their organization.                                                                                                      |
| **User Detail Page**  | A page that displays an individual user's information and provides the ability to modify a user's basic information, disable a user's access, trigger a password reset email, and update the permissions level assigned to the user. |
| **Login Method**      | How a user authenticates — **Password** or **SSO** — each shown with a status badge.                                                                                                                                                 |

## Permissions

* User Management is subject to role-based access. You must have a specific role designated by your organization to create roles and assign permissions per instance.

## Use Cases

<details open>

<summary><strong>Adding New Users</strong>  </summary>

Organizations can use User Management to add new users to the system and assign them the appropriate role. This ensures that users have access to the tools and features they need from the start.

</details>

<details open>

<summary><strong>Managing Existing Users</strong>  </summary>

Administrators can use User Management to update user information or roles at any time. This keeps user profiles accurate and ensures access levels reflect each user's current responsibilities within the organization.

</details>

<details open>

<summary><strong>Controlling User Access</strong>  </summary>

Organizations can use User Management to monitor and control who has access to the system. Administrators can deactivate users when needed, ensuring that only authorized individuals have access to the organization's tools and resources.

</details>
