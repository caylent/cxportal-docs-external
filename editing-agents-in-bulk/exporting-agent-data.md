# Exporting Agent Data

## Before You Begin

* You need access to the **Bulk Edit** section. Exporting does not submit a change and does not require Change Management approval.

***

## Step-by-Step Instructions

### Export all agents

1. Apply any filters you need to narrow the list. See [Filtering Agents.](getting-started-with-bulk-agent-management.md#filtering-agents)
2. Click **Export All** in the top-right corner of the page header.

***

### Export selected agents

1. Apply any filters you need to narrow the list.
2. Check the box next to each agent you want to export. The **Bulk Actions** toolbar appears above the table.
3. Click **Export Selected** in the toolbar.

The file downloads as a spreadsheet you can open in Microsoft Excel or a similar application.

!!! info ""
    **Info:** When you export a selection, all checked agents are included regardless of which filter is currently active.


***
